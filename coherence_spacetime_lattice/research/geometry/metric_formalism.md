# Emergent Geometry Justification

We define coherence potential:

Φ = κ − ⟨κ⟩

Define conformal metric:

g_ij = Ω² δ_ij  
Ω = 1 + α Φ

In 2D conformal geometry:

R = −2 Ω^{-1} ∇² log Ω

We use curvature proxy:

R_proxy = −∇² log Ω

This follows discrete conformal scalar curvature up to constant factors.

Consistency checks:

- Flat state κ = const ⇒ R_proxy = 0
- Small perturbations yield curvature proportional to Laplacian of κ

This is consistent with Regge-like discrete curvature where deficit angles relate to local density gradients.
